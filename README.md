# Othello AI: AlphaZero Framework with Supervised Pre-training

This repository contains the core implementation of an AlphaZero-style deep reinforcement learning agent for Othello (Reversi). The core objective of this project is to systematically compare two training paradigms under limited computational resources: **pure self-play learning (Tabula Rasa)** and **heuristic-guided supervised pre-training (Hybrid SL+RL)**. It explores their trade-offs in terms of sample efficiency and the final performance limit (playing strength).

## Key Features
* **Complete AlphaZero Architecture**: Implements a dual-head Residual Network (ResNet) combined with Monte Carlo Tree Search (MCTS) for policy evaluation and move selection.
* **Dual Training Pipelines**: The codebase supports two distinct training workflows: training from scratch using pure reinforcement learning (Pure RL), or utilizing expert data for supervised pre-training (SL) as a cold start.
* **Expert Data Generator (GreedyMCTS)**: Implements a heuristic-guided GreedyMCTS, specifically designed to generate high-quality offline game trajectories (expert data).
* **Multi-dimensional Evaluation Arena**: Features an automated cross-play evaluation module. Test opponents include traditional Minimax (with Alpha-Beta pruning) and shallow heuristic baseline algorithms, strictly evaluating the model's generalization and practical playing strength.

## Notice Regarding Large Files (.pkl / .pth)
Due to GitHub's strict 100MB file size limit, and to ensure smooth code pushing, I have excluded some large training model files via `.gitignore`.

**These excluded files primarily include:**
* **Expert Trajectory Datasets (`*.pkl`)**: Thousands of Markov trajectories generated by GreedyMCTS. These files are quite large and are primarily used for the SL pre-training phase.
* **Neural Network Weights (`*.pth`)**: Intermediate checkpoints generated during training and the final converged ResNet model weights.
* **Replay Buffer Caches**: Historical state data saved during the self-play training phase.

**How to reproduce these missing files:**
The absence of these files does not affect the integrity or execution logic of the codebase in any way.
If you want to reproduce the experiments, you can simply run the data generation scripts in the repository to regenerate the expert datasets locally. Similarly, once you initiate the training pipeline from scratch on your local machine, all model weights (`*.pth`) and replay buffer caches will be automatically generated and saved in your local directory.
